1. Unzip this patch.
2. Open the GitHub repository used for julesonthemove.com.
3. Upload the contents of `jules-on-the-move-ga4-patch` into the repository root, preserving folder paths.
4. Replace the existing HTML files when prompted.
5. Do not replace CSS, images, JavaScript, sitemap, robots, or hosting configuration. This patch does not change user-facing content or design.
6. Commit with: `Add GA4 measurement tag G-0GYX57QZD4`
7. After deployment, verify page views in your GA4 Realtime report.
